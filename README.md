# 同人誌即売会 イベントマスターCSV

日本の主要同人誌即売会の開催情報（日付・イベント名・会場・都道府県・市区町村）をまとめたCSVデータです。

> このデータは、AIアシスタント（Muse）に指示して公式サイト等を調査させ、まとめたものです。出典URLは各行に記載していますが、内容の正確さは利用時に出典で確認してください。

## ファイル

- `events-master.csv` — 全件を1本にまとめたマスター（1,233行、1975-12-21〜2027-08-29）
- `events-by-series/` — 系統別の分割ファイル（必要な系統だけ取り込みたい場合用）

## 形式

```csv
date,event_name,venue,prefecture,city,note
2024-08-11,コミックマーケット104（1日目）,東京ビッグサイト,東京都,江東区,出典:https://www.comiket.co.jp/archives/Chronology.html
```

- 文字コード: UTF-8（BOM付き）
- 1開催日＝1行。複数日開催は日ごとに展開し、イベント名に「（1日目）」「（2日目）」を付けます
- 並び順は日付順ではなく**イベントごと**（系統→地方・シリーズ別ブロック、各ブロック内は日付昇順）
- `note` には出典URLを記載しています
- 中止になった回も収録しています。その場合はイベント名の頭に「【中止】」を付け、当初予定日・予定会場で登録しています（全38行）

## データについて

- 出典は原則として各イベントの公式サイトです。公式に開催履歴が存在しない系統については、開催記録（ピクシブ百科事典・Wikipedia等）を出典として明記した上で代用しています
- 推測で日付・会場を埋めていません。確認できなかった回は収録せず、下記の欠落として明示します

### 既知の欠落

- 関西コミティアの初期〜中期の大半（公式に全回一覧がないため）
- サンシャインクリエイション初期の一部（第2〜14回など）
- COMIC CITYの2012年以前、および2013〜2021年の一部
- ZINEフェスの2022〜2023年分
- デザインフェスタ vol.4（日付未確認）
- 会場名を特定できなかった行が一部あります（会場欄が空欄の行）

これらの欠落は、今後こちらで手動調査して追加する可能性もありますが、確証が取れていないため現時点では入れていません。出典とともに追加していただける方がいれば、とてもありがたいです。
